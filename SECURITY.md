# Security Policy

## Supported versions

Only the latest commit on `main` receives security fixes.

## Report a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub: go to the repository's **Security** tab and click **Report a vulnerability**. Include:

- the affected component (engine, api, gateway, scheduler, worker, web or nginx config)
- steps to reproduce, or a proof of concept
- the impact you expect

You should get a reply within 7 days. Once a fix ships, the advisory will credit you unless you ask to stay anonymous.
